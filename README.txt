GitHub更新手順

1. https://github.com/poetsakihana/sakihana を開く。
2. Add file → Upload files を選ぶ。
3. このZIPを展開し、index.html と4つの画像ファイルを、公開中のindex.htmlと同じフォルダへアップロードする。ZIP自体はアップロードしない。
4. Commit changesで保存する。既存のindex.htmlは置き換わるので、事前にバックアップを推奨。公開元ブランチ・フォルダが違う場合は実際の公開元を選ぶ。
5. GitHub Pagesの更新後にサイトを再読み込みする。
